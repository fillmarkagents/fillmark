# Fillmark brand

| File | Use |
| --- | --- |
| `fillmark-logo-black.svg`, `fillmark-logo-white.svg` | Mark and wordmark, for light and dark backgrounds |
| `fillmark-mark-black.svg`, `fillmark-mark-white.svg` | Mark alone, for small spaces |
| `fillmark-avatar-2048.png`, `fillmark-avatar-dark-2048.png` | Profile image, 2048 x 2048, on sage or black |
| `fillmark-banner.png`, `fillmark-banner-dark.png` | README banner, 2560 x 1280 |

The SVG files scale to any size.

## Colours

| Name | Hex | Use |
| --- | --- | --- |
| Black | `#000000` | Text, logo and mark |
| White | `#FFFFFF` | Page background, logo on black |
| Sage | `#E4EBE5` | Brand background: logo lockups, avatar, banner |
| Mist | `#E2E9F0` | Panels and data areas next to sage |
| Graphite | `#5C635E` | Secondary text and captions |
| Hairline | `#D3D9D4` | Rules and borders |

## Type

The wordmark and headlines are set in Funnel Display SemiBold, released under the SIL Open
Font License 1.1.
